# Handoffs

A handoff is a release record, not a conversation summary. Write one when
something durable changes: a new module, a change to the observation contract,
a change to where the address comes from, or a published version.

Copy `_template.md`, name it `YYYY-MM-DD-topic.md`, and add a row to
`_registry.md`.

State what was actually verified and what was not. The other agent will treat
it as fact.
